# Profile

Ein Profil sagt der Factory, was für eine Art Software gebaut wird. Der Brief legt es fest (Zeile `Profil:`). Ein Projekt kann mehrere haben, z. B. `web-app, engine`.

| Profil | Für |
|---|---|
| [`web-app`](web-app.md) | Websites und Web-Apps im Browser |
| [`iphone-app`](iphone-app.md) | Native iPhone- und iPad-Apps |
| [`engine`](engine.md) | Kernlogik ohne Oberfläche, etwa Spiel-, Rechen- oder Regel-Engine, Bibliothek |
| [`backend`](backend.md) | Server, APIs, Kommandozeilen-Programme |

Jedes Profil legt fünf Dinge fest: Stack-Vorschlag, Pflicht-Prüfungen, wie getestet wird, welche Skills an welcher Station helfen, und was vor einem Release stehen muss.

Eine Station liest nur ihren Abschnitt des Profils. Stack-Angaben sind Vorschläge. Station 2 prüft den aktuellen Stand, Station 3 entscheidet.
