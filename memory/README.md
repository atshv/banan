# Projekt-Gedächtnis

Diesen Ordner zu Beginn jedes Projekts ins Repo kopieren. Er hält fest, was über mehrere Agent-Läufe hinweg gelten muss.

| Datei | Inhalt |
|---|---|
| `decisions.md` | Entscheidungen mit Grund und verworfenen Alternativen (ADRs) |
| `status.md` | Stand aller Tasks: offen, in Arbeit, fertig, blockiert |
| `lessons.md` | Fehler, die zur Regel werden |
| `conventions.md` | Namen, Begriffe, Ordner, Code-Stil |
| `questions.md` | Offene Fragen und Annahmen, die du bestätigst |
| `handoffs/` | Jede Übergabe zwischen Stationen als Datei |

## Wie es lebt
1. **Lesen.** Jede Station lädt beim Start nur, was sie braucht.
2. **Schreiben.** Beim Abschluss trägt sie Ergebnis, Entscheid und Status ein. Nur anhängen, nichts löschen.
3. **Verdichten.** Ein Curator fasst einmal pro Meilenstein zusammen. Nur er löscht Veraltetes.
4. **Zurückspielen.** Lessons werden vom Skill-Creator zu Skill- und Prompt-Regeln.
