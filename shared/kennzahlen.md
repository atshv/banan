# Factory-Kennzahlen

Kennzahlen zeigen, welche Station am meisten Probleme macht und welchen Skill du als Nächstes verbessern solltest.

| Kennzahl | Bedeutung | Warnsignal |
|---|---|---|
| Ablehnungsquote Tester | Anteil roter Testläufe | über 30 % |
| Ablehnungsquote Reviewer | Anteil abgelehnter Reviews | über 25 % |
| Versuche pro Task | Durchschnitt bis grün | über 1,8 |
| Kosten pro Task | Token oder Franken | stark steigend |
| Durchlaufzeit pro Task | Start bis Merge | stark steigend |
| Tasks an dich eskaliert | 3× gescheitert | mehr als 1 pro Woche |
| Neue Lessons | Einträge in lessons.md | gleiche Lesson mehrfach |

## Nutzung
- Der Orchestrator erfasst die Zahlen pro Task in `memory/status.md`.
- Einmal pro Meilenstein auswerten. Die schlechteste Station bekommt zuerst einen besseren Skill.
